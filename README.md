# 小朋友的寒假國語特攻隊（POC 示範版）

國小三年級國語文「冒險闖關」互動教材網站。純靜態 HTML／CSS／JavaScript，不需要任何套件或建置步驟，可以直接部署到 Netlify。

- **第一課　說文解字：文字寶藏大探險**——目標生字「探、險、迷、寶、藏」
- **第二課　成語猜謎：成語時光機**——看圖猜「守株待兔」「畫龍點睛」

人物：男孩小宇、女孩小晴，以及綁紅色頭巾的三花貓墨墨（造型參考 `resource/` 裡的海報）。

## 教材內容對照（每一課依 A～F 順序）

| 項目 | 第一課 說文解字 | 第二課 成語猜謎 |
|---|---|---|
| A 課程標題與闖關任務 | 任務一：找回森林裡的文字寶藏 | 任務二：搭上時光機，破解成語謎題 |
| B 情境圖生成描述 | `lesson1-scene.svg`＋中英文生成描述 | `idiom1-riddle.svg`、`idiom2-riddle.svg`＋中英文生成描述（圖中不出現答案文字） |
| C 短文或成語故事 | 116 字趣味短文，五個生字都在文中 | 白話成語故事＋出處＋古書原文與字詞註解 |
| D 生字詞語或成語解釋 | 注音、部首、筆畫、字形結構、說文解字小故事、字義、詞語、例句（含破音字「藏」） | 逐字解釋、比喻意思、生活例句、近義／反義成語 |
| E 互動選擇題 | 看圖找字暖身＋2 題（部首、破音字） | 每個成語：看圖猜成語＋2 題 |
| F 正確答案與簡短解析 | 作答後立即顯示，課末統整 | 作答後立即顯示，課末統整 |

成語出處：

- 守株待兔：《韓非子．五蠹》
- 畫龍點睛：唐．張彥遠《歷代名畫記．卷七》

## 網站功能

- 闖關流程：每一步都有進度列，答錯可以再試並出現提示，**第一次就答對**可以得到一顆星星（全課共 9 顆）。
- 看圖互動：第一課在情境圖上點出五個發光的生字；第二課先看圖猜成語，可以逐條打開線索，猜對後才會解鎖故事。
- 注音：生字與難字用注音標示，可以切換「隱藏注音挑戰」。
- 念給我聽：短文、成語故事、例句、生字與成語讀音，都是用 Gemini TTS 預先產生的 MP3 音檔（見下方「朗讀音檔」）；找不到對應音檔時才改用瀏覽器內建語音。
- 動態效果：插圖內建動畫（眨眼、兔子撞樹樁、閃電、飛龍）、答對彩帶、星星飛進計分欄、徽章頒發、Web Audio 音效（可關閉）。
- 通關證書：兩課都完成後可寫上名字並列印。
- 教師版（`#/teacher`）：依 A～F 列出完整教材、答案、解析與情境圖生成描述，可直接列印。
- 進度存在瀏覽器（localStorage），無痕模式下仍可正常遊玩，只是不會保留紀錄。
- 支援手機版面、鍵盤操作與「減少動態效果」設定。

## 部署到 Netlify

**方法一：連結 Git 儲存庫（推薦）**

1. 在 Netlify 選擇「Add new site → Import an existing project」，連結這個 GitHub 儲存庫。
2. 根目錄的 `netlify.toml` 已設定發布資料夾為 `site`，不需要填寫建置指令，直接部署即可。

**方法二：拖曳上傳**

打開 <https://app.netlify.com/drop>，把 `site` 資料夾整個拖進去即可。`site/_headers` 會一併套用安全性與快取設定。

**方法三：Netlify CLI**

```bash
npx netlify-cli deploy --dir=site --prod
```

## 本機預覽

```bash
cd site
python3 -m http.server 8000
# 打開 http://localhost:8000
```

也可以直接用瀏覽器打開 `site/index.html`。

## 目錄結構

```
site/                     ← 要部署的網站
  index.html
  _headers                ← Netlify 標頭設定
  css/style.css
  js/content.js           ← 所有教材文字（老師可直接修改）
  js/app.js               ← 互動程式
  js/audio-manifest.js    ← 朗讀文字與音檔的對照表（自動產生）
  images/                 ← 插圖（SVG）、海報（JPG/WebP）、網站小圖示
  audio/                  ← 朗讀音檔（MP3，自動產生）
tools/art/                ← 產生 SVG 插圖的程式
tools/audio/              ← 用 Gemini TTS 產生朗讀音檔的程式與驗證紀錄
resource/                 ← 原始海報
doc/課程.txt               ← 課程原始需求
netlify.toml
```

## 修改教材

所有文字都在 `site/js/content.js`。短文標記方式：

- `{寶|ㄅㄠˇ}`：目標生字（加注音、標示顏色，可點開生字卡）
- `[樁|ㄓㄨㄤ]`：一般難字（只加注音）

選擇題的 `answer` 是正確選項的位置（0＝A、1＝B、2＝C、3＝D）。

## 重新產生插圖

插圖是用程式畫的向量圖，同一組角色定義套用在每一張圖，確保人物造型一致：

```bash
node tools/art/build-art.mjs
```

需要 Node.js 18 以上，不需要安裝任何套件。若想改用 AI 繪圖工具重畫，可以使用教師版裡每張圖的「情境圖生成描述」（中文與英文版）。

## 朗讀音檔（Gemini TTS）

朗讀音檔在**建置前**預先產生，和網站一起部署。API 金鑰只在產生音檔的程式裡使用，不會出現在網頁中，部署後也不會產生任何 API 費用。

```bash
GEMINI_API_KEY=你的金鑰 node tools/audio/build-audio.mjs
```

- 預設模型 `gemini-3.8-flash-tts`、聲音 `Sulafat`；可用 `--voice 名稱` 換聲音，`--force` 全部重新產生，`--only 成語故事` 只重做部分段落。
- 只會產生文字有變動的段落；改完 `content.js` 後重新執行即可。
- 每段音檔產生後，會再交給 `gemini-3.8-flash` 聽寫，自動核對：內容和原文是否一致、有沒有把語氣指示念出來、語速是否正常，以及破音字讀音（寶藏的「藏」念 ㄗㄤˋ、藏在的「藏」念 ㄘㄤˊ、張僧繇的「繇」念 ㄧㄠˊ 等）。不通過會自動重做，結果記錄在 `tools/audio/audio-lock.json`。
- 這個 TTS 模型會把一般文字指示照念出來，所以語氣是用方括號標籤 `[warm, gentle ... Taiwanese Mandarin accent]` 指定。
- 自動聽寫只能抓出明顯錯誤；口音是否道地，仍建議正式使用前由老師親自試聽。
- 需要 Node.js 18 以上與 ffmpeg（含 libmp3lame）。

## 注意事項

- 製作這個示範版時，雲端環境連不到教育部「小學生字詞彙表」與「語文成果網」，所以生字是依國小三年級常見程度挑選。正式上課前，建議對照班級使用的課本版本與教育部字詞彙表，替換成當學期的生字（只要改 `content.js`）。
- 字型使用 Google Fonts 的「粉圓（Huninn）」與「霞鶩文楷 TC」；離線時會改用裝置內建字型。
